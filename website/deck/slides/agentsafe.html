The ledger

No amount from model text alone. Urdu numerals, lakh and crore, and Roman Urdu are parsed by tested code, then read back.

A person confirms. Every agent write above a set amount waits for the landlord’s tap.

Privacy first. CNICs are masked before any model call, data stays in the region and consent is recorded.

Built today: the 21 functions, idempotent payments, voids, audit records and the proofs. Proposed: the agent role and its limits.

An agent is just another unreliable client, and the database already defends against unreliable clients: a flaky phone that retries, two people paying at once, a caretaker and an owner editing the same tenancy. The agent role would be a new, read-only-by-default member with limits borrowed from Google’s AP2 payment mandates: which tenancies, the largest amount, a monthly budget, an expiry. Its check would be one more function pinned by the same test allowlist. We would also extend the TLA+ payment model with an agent that retries, reorders and duplicates, and ship the audit screen before any agent can write.
