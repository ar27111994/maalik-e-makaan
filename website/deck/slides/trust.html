This is the moat for the agentic era. The rules live in Postgres, not in the app: row-level security on every table, explicit grants, and 21 SECURITY DEFINER write functions pinned by a test allowlist, each checking the caller’s role. Payments need an idempotency key, so the same payment sent twice is recorded once. The formal models cover payment retries, receipts, late fees and the order locks are taken in; Z3 checks for overflow and rounding, and Bend checks the laws against deliberately broken versions. 1,755 app tests passed on 11 November 2026.
