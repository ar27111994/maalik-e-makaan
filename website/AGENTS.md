# website/AGENTS.md

The public site: static Astro, English at `/` and Urdu at `/ur/` (right to left, in Noto Sans
Arabic), no tracking, deployed to Vercel by the Deploy workflow. The root
[`AGENTS.md`](../AGENTS.md) rules apply. [`README.md`](README.md) is the full guide: code layout,
design system, calculators, content, adding a page or a guide, security headers.

## Rules here

- Every page has its twin in the other language with the same slug under `/ur`; the build fails
  without it. Copy lives in `src/content/` (YAML or Markdown, one file per language) and
  `src/i18n/ui.ts`.
- English is British English; Urdu is in Urdu script, never Roman Urdu. A Latin word on an Urdu
  page sits in `lang="en"` (and the reverse); the e2e suite checks it.
- In Urdu text a number range such as "2026-27" sits in `<span dir="ltr">`, or the bidi algorithm
  draws it "27-2026". `SourcesList` does this for source titles; `tests/e2e/rtl.spec.ts` checks
  every Urdu page.
- No inline scripts or styles (the build guard and the Content-Security-Policy refuse them); the
  one browser script is `src/scripts/calculator.ts`.
- Urdu text is Noto Sans Arabic. Nastaliq (Noto Nastaliq Urdu) sets only the brand name مالکِ مکان
  where it is the wordmark: the header, the Open Graph cards and the deck's cover (D-19). The
  e2e suite fails on any other Nastaliq text, and on a character the font subsets lack.
- Colours and sizes come from `design/tokens/maalik.tokens.css` (generated by `make tokens`;
  never edit it here). Stylelint allows logical properties and `--mm-color-*` colours only.
- `src/lib/money/` mirrors `mm_core`'s money and rent maths in integer paisa and is tested against
  `contracts/rent_math_vectors.json`. "Rs", "lakh" and their figures are joined by U+00A0, and in
  Urdu so are a figure and the unit or month after it ("30 یونٹس", "10 فیصد", "5 نومبر";
  `src/i18n/units.ts`).
- Legal and tax content is informational, dated and sourced, and says it is not advice. Tax shows
  withholding only, never final tax (D-10).
- `dist/llms.txt` and `dist/llms-full.txt` are built from the content (`src/lib/llms.ts`); the
  repository's own [`llms.txt`](../llms.txt) indexes the code documentation instead.

## Commands

```sh
cd website && npm ci
npm run dev            # http://localhost:4321/
npm run check          # astro check, tsc, ESLint, Stylelint, Prettier
npm test               # Vitest, including the contract vectors
npm run deck && npm run build && npm run test:e2e   # the pitch deck PDF, links, then Playwright with axe
make test-web          # the whole CI sequence, with Lighthouse (from the repository root)
```

Open before launch (`.planning/STATE.md`, Blockers): a native Urdu editor, a lawyer on the
privacy policy and terms, and a check of the official legal texts.
